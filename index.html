🧠 تکنیک‌های مطالعه

روی هر تکنیک بزن تا جزئیاتش باز بشه

🍅پومودورو
چیه؟ ۲۵ دقیقه تمرکز کامل + ۵ دقیقه استراحت.
  1. تایمر ۲۵ دقیقه بذار
  2. گوشی بیرون اتاق، فقط یک کار
  3. وقتی زنگ زد، ۵ دقیقه استراحت (آب، کشش، نه گوشی)
  4. بعد ۴ دور، ۱۵-۳۰ دقیقه استراحت بلند
نکته: اگه ۲۵ دقیقه کوتاهه، از ۴۵/۱۰ یا ۵۰/۱۰ استفاده کن.
🧑‍🏫تکنیک فاینمن
چیه؟ یه مفهوم رو طوری توضیح بده که یه بچه ۱۲ ساله بفهمه.
  1. اسم مفهوم رو بالای صفحه بنویس
  2. با زبان ساده توضیح بده
  3. هر جا گیر کردی، برگرد به کتاب
  4. ساده‌ترش کن، مثال بزن
بهترین برای: ریاضی، فیزیک، شیمی.
📖مرور فاصله‌دار
برنامه مرور:
  • ۲۴ ساعت بعد از یادگیری
  • ۳ روز بعد
  • ۱ هفته بعد
  • ۲ هفته بعد
  • ۱ ماه بعد
ابزار: از بخش «لایتنر» استفاده کن.
🔁یادآوری فعال
چیه؟ به جای دوباره خوندن، از خودت سوال بپرس.
  1. بعد از خوندن، کتاب رو ببند
  2. با زبان خودت خلاصه بگو یا بنویس
  3. فلش‌کارت بساز
  4. به دوست یا خانواده توضیح بده
قانون طلایی: اگه نمی‌تونی بدون کتاب توضیح بدی، یعنی یاد نگرفتی.
📝یادداشت کورنل
  1. صفحه رو به ۴ بخش تقسیم کن: عنوان، کلیدواژه (چپ)، یادداشت (راست)، خلاصه (پایین)
  2. سر کلاس، تو بخش راست یادداشت بنویس
  3. بعد کلاس، تو بخش چپ سوال بنویس
  4. آخر شب، خلاصه بنویس
🗺نقشه ذهنی
  1. موضوع اصلی وسط
  2. شاخه‌های اصلی دورش
  3. زیرشاخه‌ها
  4. با رنگ‌های مختلف
  5. آخرش از حفظ بازسازی کن
بهترین برای: فارسی، دینی، اجتماعی، جمع‌بندی فصل‌ها.
📚روش SQ3R
  1. Survey: تیترها، شکل‌ها رو نگاه کن
  2. Question: تیترها رو به سوال تبدیل کن
  3. Read: دنبال جواب بخون
  4. Recite: با زبان خودت بگو
  5. Review: همه رو یه بار مرور کن
🔀Interleaving
چیه؟ به جای خوندن یه درس برای ساعت‌ها، چند درس رو با هم مخلوط کن.
  1. ۳۰ دقیقه ریاضی، ۳۰ دقیقه فیزیک، ۳۰ دقیقه ریاضی
  2. موضوعات مشابه رو در هم تنیده مرور کن
  3. بین درس‌های سخت و آسان جابه‌جا شو
بهترین برای: ریاضی و فیزیک.
🧩Chunking
چیه؟ اطلاعات بزرگ رو به تکه‌های کوچیک بشکن.
  1. یه فصل ۳۰ صفحه‌ای رو به ۵ بخش تقسیم کن
  2. هر تکه رو جدا یاد بگیر
  3. آخر همه رو با هم ترکیب کن
🎨کدگذاری دوگانه
  1. هر مفهوم رو با یه شکل بکش
  2. فرمول‌ها رو با نمودار نشون بده
  3. واکنش‌ها رو با فلش و رنگ
چرا؟ مغز تصویر رو بهتر از متن حفظ می‌کنه.
❓سوال‌سازی عمیق
  1. «این چرا اینطوریه؟»
  2. «اگه این نبود چی میشد؟»
  3. «این کجا به کار میاد؟»
  4. «چه ربطی به قبلی داره؟»
⚡قانون ۲ دقیقه
  1. تایمر ۲ دقیقه بذار
  2. فقط یه صفحه بخون
  3. اگه خواستی ول کن — ولی ۹۰٪ مواقع ادامه میدی
🎯قانون پارتو ۸۰/۲۰
  1. پیدا کن کدوم ۲۰٪ مهم‌ترن
  2. وقت بیشتری روشون بذار
  3. جزئیات کم‌اهمیت رو کمتر
بهترین: وقتی وقت کم داری.
📋ماتریس آیزنهاور
  • 🔴 فوری و مهم: همین الان
  • 🟡 مهم ولی نه فوری: برنامه‌ریزی
  • 🔵 فوری ولی نه مهم: واگذار
  • ⚪ نه فوری نه مهم: حذف
⏰بلوک‌بندی زمانی
  1. مثلاً: «۱۵:۳۰ تا ۱۷:۰۰ فقط ریاضی»
  2. تو اون بازه، هیچ کار دیگه‌ای نکن
  3. حتی اگه تموم نشد، سر وقت عوض کن
🧠ذهن‌آگاهی مطالعه
  1. قبل شروع، ۳ نفس عمیق
  2. بپرس: «الان دقیقاً چی میخوام یاد بگیرم؟»
  3. فکر مزاحم اومد؟ تو دفتر افکار بنویس
  4. موقع استراحت کاملاً استراحت کن
📓دفتر اشتباهات
  1. هر سوالی غلط زدی، توش بنویس
  2. دلیل غلط: بی‌دقتی، نفهمیدن، فراموشی
  3. راه‌حل درست
  4. هفته‌ای یه بار مرور
  5. قبل امتحان، فقط همین دفتر رو بخون
😴خواب و تثبیت حافظه
  1. ۷-۸ ساعت خواب شبانه
  2. قبل خواب ۳۰ دقیقه، مطالب مهم رو مرور کن
  3. بدون گوشی بخواب
  4. ساعت خواب و بیداری ثابت
🏃ورزش و یادگیری
  1. روزی ۲۰ دقیقه ورزش سبک
  2. قبل مطالعه، ۵ دقیقه کشش
  3. بین بلوک‌ها، کمی قدم بزن
🍎تغذیه و تمرکز
  • صبحانه: پروتئین + کربوهیدرات
  • قبل مطالعه سنگین غذا نخور
  • آب کافی
  • میان‌وعده: آجیل، میوه، ماست
  • کافئین زیاد = اضطراب
📱مدیریت گوشی
  1. گوشی بیرون اتاق
  2. حالت هواپیما اگه لازمه
  3. اعلان‌ها خاموش
  4. اپ مسدودکننده
چرا؟ هر چک کردن، ۲۰ دقیقه تمرکز رو خراب می‌کنه.
🎯هدف‌گذاری SMART
  • Specific — مشخص: «۲۰ تست ریاضی فصل ۱»
  • Measurable — عدد داشته باشه
  • Achievable — دست‌یافتنی
  • Relevant — مرتبط با هدفت
  • Time-bound — زمان‌دار
🌱عادت‌سازی تدریجی
  1. با ۱۰ دقیقه شروع کن (نه ۲ ساعت)
  2. هر روز همون ساعت، همون مکان
  3. هر هفته ۱۰٪ اضافه کن
  4. یه روز خراب شد؟ فرداش دوباره
قانون: تداوم از شدت مهم‌تره.
🔗عادت‌سوار شدن
  1. «بعد از شام، ۳۰ دقیقه عربی»
  2. «بعد از مسواک صبح، ۱۰ دقیقه مرور»
  3. «بعد از رسیدن از مدرسه، ۱۵ دقیقه استراحت، بعد مطالعه»
