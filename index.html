📖 راهنمای منبع

برای هر درس، از کتاب بخون یا از ویدیو ببین — با نسبت و ترتیب درست.

📐
ریاضی
اول کتاب، بعد ویدیو
ترتیب: کتاب → ویدیو (اگه نفهمیدی) → تمرین
دلیل: ریاضی با تمرین یاد می‌گیری
ویدیو ۳۰٪
کتاب ۷۰٪
۱کتاب رو ۵ دقیقه ورق بزن
۲تمرین‌های آخر فصل رو ببین
۳اگه نفهمیدی، ویدیو ببین
۴۳-۵ تمرین حل کن
⚛️
فیزیک
اول ویدیو، بعد کتاب
ترتیب: ویدیو → کتاب → تمرین
دلیل: فیزیک مفهومی‌ست، تصویر کمک می‌کنه
ویدیو ۵۰٪
کتاب ۵۰٪

هندسه

ترتیب: کتاب → ویدیو → تمرین
دلیل: هندسه با شکل کشیدن یاد می‌گیری
ویدیو ۴۰٪
کتاب ۶۰٪

ترتیب: ویدیو → کتاب → تمرین

📝 خلاصه‌نویسی

⚠️ اشتباه بزرگ

❌ کپی از کتاب «مشتق تابع f در نقطه x به صورت حد نسبت تغییر تابع به تغییر متغیر تعریف می‌شود.»
✅ با زبان خودت «مشتق = سرعت تغییر. مثل کیلومترشمار ماشین که سرعت لحظه‌ای رو نشون میده.»

📘 روش ۱: یادداشت کورنل

📐 تقسیم دفتر

🔑 کلیدواژه‌ها

(بعد از کلاس)
• Δ چیه؟
• کی دو جواب داره؟
📝 یادداشت

(سر کلاس)
معادله درجه دو: ax² + bx + c = 0
روش‌ها: تجزیه، فرمول Δ، مربع کامل
Δ = b² - 4ac
📌 خلاصه: معادله درجه دو رو با ۳ روش میشه حل کرد. سریع‌ترین راه، فرمول Δ هست.
۱صفحه رو ۴ بخش کن
۲سر کلاس تو بخش راست بنویس
۳بعد کلاس تو بخش چپ سوال بنویس
۴آخر شب خلاصه بنویس

🗺 روش ۲: نقشه ذهنی

🎯 برای مرور کل فصل

تجزیه │ فرمول Δ ──── معادله درجه دو ──── مربع کامل │ ax² + bx + c = 0
چطور؟
۱. موضوع اصلی وسط
۲. شاخه‌ها دورش
۳. با رنگ‌های مختلف
۴. آخرش از حفظ بکش

🎴 روش ۳: فلش‌کارت

✨ برای لغت و فرمول

روی کارت: ترجمه: ذَهَبَ الطّالِبُ إلَی المَدرَسَة
پشت کارت: دانش‌آموز به مدرسه رفت
۱کارت ۱۰×۱۵
۲یه طرف سوال، یه طرف جواب
۳روزی ۱۰-۱۵ کارت

📋 هر درس چطور خلاصه بشه؟

📐 ریاضی: نقشه ذهنی فصل + فلش‌کارت فرمول
⚛️ فیزیک: نقشه ذهنی + دفتر فرمول
📏 هندسه: هر قضیه با شکل
🧪 شیمی: جدول واکنش‌ها
🕌 عربی: فلش‌کارت لغت + کورنل قواعد
🌐 انگلیسی: فلش‌کارت لغت + کورنل گرامر
📜 فارسی: نقشه ذهنی آرایه + کورنل دستور

اگه نتونی بدون کتاب با زبان خودت توضیح بدی،
یعنی هنوز یاد نگرفتی.
